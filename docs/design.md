# Moss Survivor

Approved scope: Phaser 3 + TypeScript + Vite; public GitHub repository Llonvne/moss-survivor; browser demo hosted on Sites. Single player, no backend, no accounts added by the game.

One pixel-art mage survives a grassland arena. WASD/arrows or touch joystick moves; bolts automatically target nearby enemies. Three enemy types approach from outside the view. Kills drop experience. Each level pauses combat and offers three distinct upgrades. At 4:15 a boss appears; defeat the boss and survive until 5:00 to win. If alive at 5:00 with boss alive, battle continues until it is defeated. Death shows statistics and restart. Pause and hidden tabs freeze simulation.

First version supports desktop and mobile browsers; native app packages and consoles are outside this prototype. Chinese interface. Original procedural pixel sprites and synthesized optional sound. No external asset requests during gameplay.
